# Subtitle Studio: аудит и что изменено

## Что было (по коду и живому прогону на 390×800)
| Область | Состояние |
|---|---|
| Разрешения | Камера и микрофон запрашивались при открытии страницы, без объяснения. При отказе только тост на 9 с. Кнопки «повторить» не было. |
| Установка | `manifest.webmanifest`, `sw.js`, `icon-180.png` не входили в поставку. Кнопка установки скрыта правилом `body.flowon #inst{display:none!important}`. |
| Телефон без ключа | Запись блокировалась окном «нужен ключ Groq» без кнопки «продолжить». |
| Язык | По умолчанию EN, переключатель скрыт в режиме мастера. В интерфейсе остаются русские строки. |
| Загрузка видео | Только кнопка. Без перетаскивания, без проверки типа файла. |
| Экспорт | Всплывающее окно с именем, затем скачивание. Экрана «Готово» нет, публикация только через скрытое меню. |
| Цвета | Тёмная палитра, контраст основного текста 5.6–12:1. Белый на розовом конце градиента 3.5:1. |
| Мелочи | Тосты закрывали кнопку «Далее». У иконок шапки и кнопки «Назад» не было подписей. |

## Что стало
1. Шлюз доступа на сцене: объяснение, «Разрешить», состояния «закрыт» / «ошибка» / «нет API», кнопка «Загрузить видео». Если разрешение уже выдано, камера включается сама.
2. Камера не включается без действия пользователя или выданного разрешения.
3. Установка: иконка в шапке, карточка на экране «Готово», готовые manifest, service worker и иконки.
4. Телефон без ключа: кнопка «Продолжить без ключа» (текст распознаётся после остановки).
5. Язык по умолчанию = язык устройства, переключатель в «Настройки». Новые экраны на EN / RU / ՀԱՅ.
6. Загрузка: перетаскивание, проверка типа файла.
7. Экспорт: поле имени файла, строка о формате, экран «Готово» (просмотр, Поделиться, Сохранить, описание, 8 площадок, .srt, установка, «Назад к правке», «Новое видео»).
8. Тосты в режиме мастера над шторкой, подписи у иконок и шагов.
