What I work on

My work sits between backend engineering, applied AI, and economic analysis. I've built backend systems and algorithmic trading infrastructure, and more recently have been integrating large language models directly into working systems rather than bolting them on as a feature. I'm also experimenting with reinforcement learning — more as a way to probe how systems learn than as something I'd call a strength yet.

Underneath most of this is the same habit: noticing where an explanation doesn't quite fit, and following that thread until it turns into something testable. I also write on process philosophy and economics, since the same patterns tend to repeat there too.

Working with AI

I use AI systems, including Claude, as core infrastructure rather than a convenience layer — architecting the plumbing that lets a model act, not just answer. That means working directly with APIs, designing the surrounding system so the model's output is actually load-bearing, and treating the model itself as a component to be engineered around, not a black box to prompt and hope.

It also functions as a thinking partner: a fast way to stress-test an idea, pressure it from an unfamiliar angle, or check whether a pattern I've noticed in one domain actually holds up in another.

How I think

I think abductively — starting from a contradiction, an observation that doesn't quite fit, and working backward to the structure that would explain it, then testing whether that structure holds somewhere else, rather than starting from a hypothesis and building forward. Ideas tend to arrive as structural isomorphisms: a shape I've noticed in one domain — a feedback loop in a market, a pattern in how a conversation breaks down, an incentive that quietly contradicts its own stated goal — reappearing almost unchanged in a completely different one.

I lean toward process over static categories: what matters is usually how something is unfolding, not the label it's been given. In practice this means I spend less time asking "what is this" and more time asking "what is this doing, and where else have I seen it do that."
